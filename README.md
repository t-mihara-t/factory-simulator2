# RAILWORKS YARD — Factory Simulator 2

広い鉄道車両工場を探索し、設備・人・物流・利益を育てる工場経営シミュレーション。
旧作 `factory-simulator` の8車種・音声・車両素材を引き継ぎ、生産システムと画面を刷新したプロトタイプです。

## 0.4の変更

初回は「編成 → 受注 → 設計・材料手配 → 製造 → 工場出荷・入金」を実際に操作するチュートリアルから始まります。各工程を1〜3並列で編成でき、操業後も人員配置までまとめて増設できます。

管理画面のタブを移動しながら、編成・人員・受注・資材・生産計画・出荷・お金を続けて調整できます。現金と未入金の完成品を分け、前倒し出荷、次の変化までの時間送り、選択式の応援便、納期内連続出荷ボーナスを追加しました。

## 遊ぶ

`dist/index.html` をブラウザで開いてください。依存ライブラリのインストールは不要です。Windowsでは `01_PLAY.bat` から起動できます。

1. 最初に各工程の並列数を決め、観光旅客車1両を受注します。
2. 受注伝票を設計へ送って操業開始。材料手配時に現金が減ることを確認します。
3. 「次の変化まで」で着工・入荷・工程完了を追えます。大切な操作の前では時間が止まります。
4. 完成品倉庫に届いたら「工場出荷する」。ここで初めて売上が入り、チュートリアルが完了します。
5. 次の商談を受け、タブで全体を調整。必要な工程を2・3並列にし、納期内の連続出荷を目指します。

マップはドラッグ・ピンチ・ホイールで移動・拡大縮小。管理画面では一時停止し、閉じると開く前の操業状態に戻ります。タブ間の移動では再開しません。

旧セーブの工場はそのまま続けられます。入門をやり直すときは「設定 → シナリオ選択 → 潮風の車両工場」。現在の途中保存を置き換える確認画面が出ます。

## 内容

- 38×30の等角マップ、ミニマップ、6施設、8車種
- 建設・改良・撤去・用地拡張、採用・減員・人員配置
- 有限の工程待ちと中間倉庫、建物を避ける経路、距離を反映した運搬
- 故障・予防保全・臨時受注・改善イベント
- 受注と投入の分離、仕掛上限、納期順／到着順
- 出荷売上と資金・利益の区別、前倒し便、在庫原価、給与、再投資
- 体験チュートリアルと4章の入門、受注波、故障復旧、調達、設計並列化、着工予約、自由経営
- BGM・SE、1×/2×/4×、ブラウザ内保存
