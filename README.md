# RAILWORKS YARD — Factory Simulator 2

広い鉄道車両工場を探索し、設備・人・物流・利益を育てる工場経営シミュレーション。
旧作 `factory-simulator` の8車種・音声・車両素材を引き継ぎ、生産システムと画面を刷新したプロトタイプです。

## 0.3の変更

営業窓口から伝票を設計へ送り、設計後に材料を調達して、資材置場から加工へ運びます。車種別の先行在庫と時間ごとの保管料、着工予約と材料待ちを反映したガント、完成品倉庫の数量バッジ、専用の達成・失敗画像を追加しました。

「海を渡る資材」「特急デザイン室」「時刻表に合わせて」を追加し、6シナリオと自由経営を遊べます。スマホの縦横レイアウト、折りたたみ情報、人員・経路設定、作業アニメーションを継続しています。

[デモで遊ぶ](https://factory-simulator2.tomonobumihara.chatgpt.site) · [変更内容・費用・予測条件](docs/CHANGES_V03.md)

## 遊ぶ

`dist/index.html` をブラウザで開き、「操業開始」を押してください。依存ライブラリのインストールは不要です。
Windowsでは `01_PLAY.bat` から起動できます。

1. マップをドラッグして移動。設備をタップすると配置・修理・改良を操作できます。
2. 受注済みの3両の伝票が営業から設計へ。設計後に材料調達→加工→組立→検査→出荷へ流れます。
3. 最初の未配置2人を詰まった工程へ配置。「受注」で次の注文を受けます。
4. 目標を開いて報酬を受け取り、倉庫・設備・用地に再投資します。完成品は納期まで保管されるので、材料費・給与・保管費を残してください。

スマートフォン：1本指で移動、2本指で拡大縮小。PC：ドラッグ、ホイール、マップにフォーカスして矢印キー。管理画面では一時停止し、閉じると元の状態に戻ります。

## 内容

- 38×30の等角マップ、ミニマップ、6施設、8車種
- 建設・改良・撤去・用地拡張、採用・減員・人員配置
- 有限の工程待ちと中間倉庫、建物を避ける経路、距離を反映した運搬
- 故障・予防保全・臨時受注・改善イベント
- 受注と投入の分離、仕掛上限、納期順／到着順
- 出荷売上と資金・利益の区別、在庫原価、給与、再投資
- 4章の入門、受注波、故障復旧、調達、設計並列化、着工予約、自由経営
- BGM・SE、1×/2×/4×、ブラウザ内保存

## 開発と確認

Node.js 20以上。`node --test tests/*.test.js` と `npm run check`。
ビルド不要のHTML/CSS/JavaScript。配信対象は `dist/` です。

34件のロジック検証に合格。6シナリオの達成可能性を自動操作で確認しました。端末内保存のみで端末間同期はありません。
