# 納期前の出荷禁止と、早すぎる完成を防ぐ戦略

この文書はv0.4.2時点の記録です。受注直後の予約検討と約40秒の最新デモは [v0.4.3の変更](CHANGES_V043.md) を参照してください。

完成した車両は出荷倉庫で納期まで保留します。前倒し出荷はできません。出荷ボタン・前倒し便の手数料を廃止し、シミュレーション内部でも納期前の出荷・入金を拒否します。通常プレイ、チュートリアル、自動デモ、生産計画の予測が同じルールです。

| タイミング | 車両とお金 |
|---|---|
| 材料手配 | 材料費を先払い |
| 製造完了・出荷倉庫へ到着 | 売上・入金は0G。納期まで1両につき0.90G / ゲーム秒の保管料 |
| 納期 | 自動で工場出荷。ここで売上・入金・出荷済み材料原価を計上 |
| 納期後に完成・到着 | 直ちに出荷し、従来の遅延控除を適用 |

給与と設備維持費は、完成品の保管中も発生します。完成済みの車両を納期前に換金して資金不足を解消することはできません。

## チュートリアルとデモ

- 最初の受注時から「前倒し出荷不可」を説明。
- 完成時に停止し、未入金額、納期までの残り時間、残り保管費を表示。
- 着工予約、受注量・仕掛上限、必要な工程への応援・増設という3つの戦略を説明。
- 「納期まで時間を進める」で通常の0.1秒刻みの処理を実行し、保管料・給与・維持費を精算してから納期出荷。プレイヤーが待つ時間は増やさない。
- 初出荷後にも同じ戦略を振り返り、生産計画の着工予約へ移動できる。
- 自動デモは約35秒。検証では32.65秒で完走し、ゲーム内の出荷時刻は160秒。製造完了は87.5秒なので、完成後の保管費は65.25G。
- 通常操業でも、完成品の納期待ちだけなら快適モードで8×進行。故障・資金不足・遅延リスク・商談や応援の判断は従来通り減速する。

## 伝える戦略

1. **納期から逆算して着工予約。** 設計・材料リードタイム・運搬・工程待ちに余裕を加えた時間を残す。ぎりぎりまで遅らせず、生産計画で予測を確認する。
2. **受注量と仕掛上限を抑える。** 遠い納期の案件を同時に着工しない。次の出荷までの材料費・給与・維持費を現金で確保する。
3. **応援と増設は遅れそうな工程へ。** 納期前の完成品を増やすだけの加速を控え、実際の制約を改善する。

最初の1両を同じ人員・経路、追加の故障や混雑なしで比べると、着工予約を60秒遅らせたケースでも160秒の出荷と4,300Gの売上を維持できます。保管費は65.25Gから11.34Gへ減り、差は53.91G。画面では概算として「約65G → 約11G、約54G削減」と表示します。材料費の支払いも約60秒後ろへずれます。給与・維持費は同じ時間分掛かり、着工の繰り延べだけでは減りません。

## 保存と検証

保存形式v5。v1〜v4の進行・残高を引き継ぎます。旧チュートリアルの出荷待ちは同じ納期の新しい案内へ移行。旧ルールで既に出荷した分の売上や費用は書き換えず、前倒し便費は履歴として残します。デモは通常の工場保存を上書きしません。
