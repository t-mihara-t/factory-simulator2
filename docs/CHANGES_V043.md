# 受注直後にガントを見て着工予約を決める

受注した直後に、その案件を選択した生産計画を開きます。予約時刻の変更に合わせてガントと費用を更新し、プレイヤーが確定してから操業へ戻ります。

## 操作の流れ

1. 商談の「受注して着工予約を検討」を押す。
2. 選択した受注を強調したガントで、既存案件との工程の重なり、完成、納期までの保管期間を確認する。
3. 着工時刻を変更し、完成予測・納期余裕・完成品の保管費見込を比較する。人員・資材のタブへ移動したり、同じ画面の経路設定を変えたりできる。
4. 「この着工予約で確定・操業へ」で確定する。予約時刻と工程の空きが整うと、営業から設計へ伝票を送る。

管理画面とタブ移動中は時間が止まります。未確定の案件は、画面を閉じてほかの生産を再開しても着工しません。未確定のまま保存した工場を再開すると、生産計画を開きます。納期自体は動かないため、工場へ戻って時間を進めた場合は再度ガントを確認してください。

## ガントと費用の読み方

| 表示 | 意味 |
|---|---|
| 着工マーカー | 予約時刻と人員・設備・待ち枠を踏まえた着工見込み |
| 完成予定 | 選択した受注の、残っている最終車両が出荷倉庫へ到着するまで |
| 納期余裕 | 完成から納期まで。納期を超える予測は遅延として表示 |
| 橙色の保管期間 | 完成しても出荷できず、納期まで倉庫に置く期間 |
| 保管待ち・保管費見込 | 今から出荷までの全車両の保管時間合計と、0.90G / 両・ゲーム秒での費用 |

予測は、選択した受注を確定して自動着工を有効にする条件で、通常のゲームと同じエンジンから計算します。他の未確定案件は着工させず、「着工予約が未確定」と表示します。人員・資金・経路などで完成を見通せない場合は未確定を示し、納期内だと誤表示しません。将来の商談・ランダムイベント・プレイヤーの追加修理は含みません。

前倒し出荷はできません。着工予約を遅らせると材料支払いと完成を後ろへ寄せられますが、納期までの給与・維持費は別途必要です。保管費を減らす場合も、混雑や故障に備える余裕を残しましょう。

## チュートリアルと自動デモ

チュートリアルの受注後にガントで予約を検討し、確定する手順を追加しました。自動デモは最初に即時着工の予測を表示し、60秒後の着工に変え、保管費見込が約65Gから約11Gへ変わる様子を示してから確定します。

自動デモは約40秒（固定ステップの検証では38.70秒）で完走。予約待ちはデモ内で32×に短縮し、通常プレイの予約待ちも安全な場合は快適モードで8×進行します。通常プレイでは「次の判断まで」も使えます。ゲーム内の納期は160秒のままで、147.4秒に完成、納期の工場出荷で4,300Gが入金され、完成品保管費は11.34Gです。説明・判断の節目で停止し、通常の保存は上書きしません。

## 保存と検証

保存形式v6。v1〜v5を引き継ぎ、既存の受注やシナリオ初期受注の着工状態・残高は維持します。

68件の自動テストが合格。新たに未確定予約の着工防止・保存再開・確定後の時刻制約、ガント予測と実際の費用、遅延と予測不能の区別、受注直後の画面遷移・タブ移動・デモ内の比較を確認しました。全6シナリオ、既存のチュートリアル、納期前出荷禁止の回帰検証と構文・静的参照チェックも合格しています。UI操作は実際のアプリ制御をDOMアダプターで検証し、実機ブラウザの描画・音声・性能は今回の検証に含みません。
