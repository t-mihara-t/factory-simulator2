# オープニング・自動デモ・待ち時間の短縮

> このページは当時の変更記録です。現行ルールでは前倒し出荷を禁止しています。[v0.4.2の出荷ルール・攻略戦略](CHANGES_V042.md)を参照してください。

入口で「チュートリアルで遊ぶ」「自動デモを見る」「保存した工場の続きから」を選べます。設定からも入口へ戻れます。既存の途中保存を新しい工場で置き換える場合は、画面内で確認します。

自動デモは、組立2並列のライン編成、1両の受注、着工、材料費2,850Gの支払い、製造、工場出荷による4,300Gの入金までを約29秒で実行します。実際のシミュレーションと操作を使い、材料費・給与・維持費を省略しません。各説明には読む時間があり、一時停止・再開・終了もできます。完了後は自分で遊ぶ入口につながります。

デモの途中・完了時・ページを閉じたときにも、通常の工場保存へは書き込みません。ブラウザを離れたときは自動停止します。以前のセーブは同じ状態から再開できます。

## 待ち時間

| 状態 | 快適モードの進行 |
|---|---|
| 通常の作業 | 4× |
| 全車両が運搬・材料調達中 | 8× |
| 納期直前、故障、資金不足、手動退避、応援イベント | 手動速度へ戻る（初期2×） |
| 通常操業の完成品・締切間近の商談 | 手動速度へ戻る |
| チュートリアルの操作・説明、管理画面 | 停止 |

「快適」は初期設定で有効。時間バーの「快適」「1×」「2×」「4×」、または設定で変更できます。給与・維持費・保管料・納期も同じゲーム時間で進みます。ゲーム内の残り秒数と実際の速度を表示します。

「次の判断まで」は着工、材料購入、工程完了、入荷、故障、商談、出荷などの節目で止まります。通常の運搬到着・作業開始だけで細かく止まることを減らしました。1回の上限は60ゲーム秒で、チュートリアルの確認を飛ばしません。

## 画面

既存の工場・車両画像を、見出しや説明とは独立した領域へ配置。入口は広い画面で2列、狭い画面で縦配置になり、高さが不足したらスクロールできます。自動デモの説明・停止ボタンはマップや管理画面の本文と領域を分けています。

## 検証

- `npm test`：58件成功。全6シナリオの既存検証を含む。
- 自動デモを毎秒60フレームで実行：29.25秒で初出荷。シミュレーション内では87.5秒。
- 手動チュートリアルの待機区間：快適進行で17.27秒。説明や操作中は時間を消費しない。
- デモ一時停止・復帰、バックグラウンド停止、保存保護、旧工場への復帰、新規開始の確認、管理タブの移動、手動チュートリアル完走を実際のアプリ制御処理で検証。
- 材料購入・製造完了・工場出荷の会計を分離したまま、資金残高が一致することを確認。
- `npm run check`：JavaScript構文、操作ID、入口とローカル素材参照を確認。

アプリ制御の検証はDOMアダプターを使い、画像描画と音声を代替しています。実ブラウザの見た目・実機の操作・音声の検証とは異なります。
