# v0.4 — 自分で編成し、出荷まで動かす工場

初めて起動したときと、「潮風の車両工場」を新しく始めたときは、実際の操業を操作するチュートリアルから始まります。

## 最初の6ステップ

1. 設計・加工・組立・検査を、それぞれ1〜3並列で編成。
2. 観光旅客車1両を受注。受注時の支払い・売上は0G。
3. 操業開始。営業から伝票が設計へ移動。
4. 設計後の材料手配を確認。材料費2,850Gは手配時に支払う。
5. 完成品倉庫に到着した車両を手動で工場出荷。完成だけでは売上は入らない。
6. 出荷売上4,300Gの入金を確認し、次の3件の商談から通常操業へ。

操作が必要な節目では時間が止まります。ガイドを閉じても「案内を開く」から戻れます。練習の商談を見送って進行不能になる操作は防止しています。ガイドの途中も保存できます。

## 編成・調整

- 管理画面は全画面。編成／人員／受注／資材／生産計画／出荷／お金／建設／出来事をタブで直接移動。
- タブを切り替えても操業は停止したまま。スクロール位置と開いた詳細をタブごとに保持し、調整結果は同じ工場に即時反映。
- タブは左右矢印、Home、Endでも操作可能。
- 初期編成は「組立2並列」「小さく始める」「設計3並列」「全工程2並列」のプリセットと、各工程の個別指定。
- 開業時の設備枠は38,000G。超過額だけを現金から支払い、開始時の現金は材料・運営用に12,500G以上を残す。枠の余りは換金しない。
- 開業時は1棟に2人、全従業員は最低10人。設備や人員を増やすほど維持費・給与が増える。
- 通常操業では工程ごとの増設ボタンで2・3並列へ。必要な採用、2人の配置、空き区画への配置まで一括実行。費用不足や用地不足では変更しない。
- 3並列を超える設備は従来の建設画面で個別に配置できる。

## お金と工場出荷

| 時点 | 現金 | 売上・費用の扱い |
|---|---|---|
| 受注 | 変化なし | 約束のみ |
| 材料発注・先行手配 | 材料費を支払う | 出荷までは在庫原価 |
| 操業 | 給与・維持費を支払う | ゲーム時間に応じた費用 |
| 完成品倉庫 | 保管料を支払う | 売上はまだ0G |
| 工場出荷 | 売上が入金 | 出荷した車両の材料原価も費用化 |
| 前倒し出荷 | 入金後に売価の2%を支払う | 追加輸送費として計上 |

通常の受注は従来通り、納期に自動出荷します。「出荷」タブでは完成品倉庫に到着済みの車両を前倒し便で今すぐ出荷できます。チュートリアルの最初の1両は手動出荷で、前倒し便の追加費用は無料です。

納期遵守は実際の工場出荷時刻で判定します。完成していても、手動出荷を納期後まで遅らせれば遅延です。

現金、完成・未入金の売上見込、これからの材料費、現在の状態を60秒維持する運営費、追加投資の目安を分けて表示します。「追加投資の目安」は現金から材料費と60秒分の運営費を控除した参考値です。将来の受注・在庫・費用変動まで保証する値ではありません。

発注・投資・出荷などの直近24件を入出金履歴に表示。給与・維持費・保管料は継続発生するため帳簿に集計します。

## 待つ時間にも判断を

- 「次の変化まで」は通常の0.1秒刻みのシミュレーションを使い、着工・入荷・工程状態変化・出荷・新規商談・故障などの最初の変化で停止。1回最大60ゲーム秒。給与や保管料も通常通り精算する。
- 通常の新規商談の間隔を34秒から24秒へ短縮。「注文が押し寄せる街」は18秒を維持。
- 応援便のイベントを追加。選んだ工程を35秒間35%加速（220G）するか、到着待ちの材料を最大12秒早める（180G）か、見送るかを選ぶ。受付は32ゲーム秒。
- 納期内出荷3連続ごとに信頼ボーナス。3連続で300G、6連続で600G、9連続以降は3両ごとに900G。遅延すると連続数がリセットされる。売上には混ぜず助成収入として記録。
- 工程ごとの並列数・作業棟数・待ち両数と、完成・未入金額をマップの外に常時表示。次に判断できることを状況に応じて案内する。

## 文字と画像

管理画面は画像と本文の枠を分離し、PCでもスマートフォンでも全画面を使います。工程カードは画面幅に応じて4列・2列・1列に変わり、タブは横スクロールできます。

マップのラベルは画面上の文字領域と画像領域を一緒に判定して配置します。場所が足りないラベルは重ねて描かず、マップ外の工程表示・管理画面で確認できます。納期5秒以内と選択中の設備を優先表示します。
