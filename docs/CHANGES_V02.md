# 0.2.0 — 工場を主役にする改修

## 操作と見え方

- タイトル帯を撤去。上部は運転資金と出荷量だけを表示。
- 目標・通知・全域地図・設備詳細は一度に一つを開く。閉じると工場領域へ戻す。
- 横持ちの低い画面では操作メニューを右端へ配置。詳細は横側、縦持ちは下側の別領域に表示する。
- 管理画面は横持ちでは右側、縦持ちでは下側。開いている間は生産を停止し、残った画面に工場を表示する。
- カメラの初期倍率は表示領域と設備配置から計算する。プレイヤーが移動・拡大した後はその中心を保持する。
- 資材台車→図面・部品→台車・車輪→組立車体→完成車両と、工程進捗に応じて表示を変える。右上の小さな車種画像は完成予定の車両。
- 工程別に製図、加工、組立、検査の2姿勢を切り替えて作業を表す。停止・演出OFF・動きを減らす設定に対応。
- 納期表示と施設名はマップの倍率と独立した文字サイズ。残り5秒以下を強調する。
- 最終目標の達成後は PERFECT SCHEDULE、資金0Gで GAME OVER を表示。紙片・文字・列車の演出と音を付け、演出OFF時も結果は伝える。

## 生産と費用

| 支出 | ルール |
|---|---|
| 採用費 | 採用1人につき350Gを一度支払う |
| 給与 | 未配置を含む全従業員 × 0.48G / ゲーム秒 |
| 工程前の待ち場所 | 順番待ち・後工程待ち1両 × 0.60G / ゲーム秒 |
| 中間倉庫 | 保管1両 × 0.25G / ゲーム秒 |
| 完成品倉庫 | 到着から納期まで1両 × 0.90G / ゲーム秒 |

完成品は既設の出荷ゲート併設倉庫で納期まで保管する。納期になると出荷し、売上と材料原価を認識する。納期を過ぎて到着した車両はその時点で出荷し、遅延控除を計上する。完成品は製造中の上限から除く。在庫の材料価値は出荷まで保持する。

中間倉庫があれば、作業前または工程完了後の待ち車両を手動で退避できる。手動退避は「出庫を再開」を押すまで待機する。自動退避品は後工程の空きに応じて自動出庫する。作業途中の工程を中断して移す機能は含めない。

## 経路・着工予約・ガント

各工程に2棟以上ある場合、工場全体の標準経路と受注ごとの経路を選択できる。自動は残り負荷と距離で選択し、手動指定はその設備の空き・復旧・配置を待つ。運搬中・作業中の行先を変更しない。撤去した設備の指定は解除する。

未着工分の着工を「今から0 / 15 / 30 / 60 / 90 / 120 / 180秒後」に予約できる。予定時間になっても、材料資金・投入上限・行先の空きが必要。早作りの保管料と納期リスクを比較する判断材料とする。

ガントは描画専用の作り物の時刻ではなく、実際のシミュレーション状態を複製して先に進めた結果。1設備の作業枠は1両、待ち枠は2両。人員、設備レベル、指定経路、距離、修理、劣化、有限の待ち枠、投入上限、資金と継続費を反映する。受注1両ごとの残り工程、運搬、待ち、保管、納期線を表示する。

管理画面で人員・経路・着工予約・投入方針・修理を変えるたびに再計算する。計算は分割して画面操作を止めず、古い計算結果を後から上書きしない。先のランダムイベント、新規受注、まだ指示していない修理・配置操作は予測しない。最長30分先までに終わらない仕事は完了未確定と表示する。

## 保存と互換性

保存スキーマ2。旧スキーマ1の資金・受注・在庫を維持して新しい項目を補う。旧保存の過去の保管料は中間倉庫費に引き継ぎ、新ルールの料金は更新後の進行から適用する。旧作factory-simulatorの保存キーは使用しない。

## 検証

26件の自動テストに合格。車両保存、給与・初期費、保管費、納期での出荷、経路の優先関係、手動退避、ガントの設備枠非重複、人員変更、予約、保存互換を確認。

同一の既定操作で、入門は1171ゲーム秒・23両、受注波は759秒・21両、復旧は669秒・12両でクリアした。初見プレイヤーの時間ではない。HTML参照・コントロールID・JavaScriptの構文を確認。縦・横・管理画面表示中の5つの描画領域で、工場の収まりとカメラの中心維持を計算上確認。今回ブラウザの操作試験とスマホ実機の縦横回転、音声、描画性能は未実施。
